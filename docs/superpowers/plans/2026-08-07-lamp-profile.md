- [ ] **Step 1: Write the STL generator**

```python
#!/usr/bin/env python3
"""Generate a 60mm open-top box as a binary STL (vase-mode-like test part).

Normals are written as zeros on purpose - print_advisor recomputes them from
vertex winding, and this exercises that path (AGENTS.md lesson #9).
"""
import struct

S = 60.0
quads = [
    [(0, 0, 0), (0, S, 0), (S, S, 0), (S, 0, 0)],  # bottom (faces -Z)
    [(0, 0, 0), (S, 0, 0), (S, 0, S), (0, 0, S)],  # front  (y=0)
    [(S, 0, 0), (S, S, 0), (S, S, S), (S, 0, S)],  # right  (x=S)
    [(S, S, 0), (0, S, 0), (0, S, S), (S, S, S)],  # back   (y=S)
    [(0, S, 0), (0, 0, 0), (0, 0, S), (0, S, S)],  # left   (x=0)
]
tris = []
for a, b, c, d in quads:
    tris.append((a, b, c))
    tris.append((a, c, d))

out = __file__.rsplit('/', 1)[0] + '/test_shade.stl'
with open(out, 'wb') as f:
    f.write(b'\0' * 80)
    f.write(struct.pack('<I', len(tris)))
    for t in tris:
        f.write(struct.pack('<3f', 0, 0, 0))
        for v in t:
            f.write(struct.pack('<3f', *v))
        f.write(struct.pack('<H', 0))
print('wrote', out, 'with', len(tris), 'triangles')
```

Save as `$SCRATCH/make_test_stl.py`, then run: `python3 $SCRATCH/make_test_stl.py`
Expected: `wrote .../test_shade.stl with 10 triangles`
